Software

Neuroimaging

NIRSPipe

A BIDS-compatible pipeline for fNIRS preprocessing, postprocessing, hyperscanning, and quality control. Each run gets an HTML QC report with a provenance graph and a generated Methods paragraph. In active development.

Code · Documentation

NeuroMaestro

A modular neuroimaging preprocessing meta-pipeline for HPC clusters, with a GUI and a CLI. Data preparation, AFNI or BIDS-app pipelines (fMRIPrep, XCP-D, QSIPrep), and MRIQC run on SLURM and are configured through YAML files.

Code · Documentation · PyPI

fMRI-QCtoolkit

fMRI quality control that combines quantitative metrics from MRIQC, fMRIPrep, and AFNI with manual ratings, plus an interactive dashboard for filtering and reviewing a whole dataset.

Code · PyPI

ConnGraph

Graph-theory metrics, group comparisons, and network-based statistics for brain connectivity from fMRI, fNIRS, EEG, and MEG, with HTML reports and 3-D brain figures.

Repository not yet public

Research data and workflow

AILR

A desktop app for systematic and scoping literature reviews with an AI as a second reviewer, from import and deduplication through screening and data extraction, with a PRISMA-auditable trail.

Code · Documentation

labcatalog

A browsable catalog of a lab's study data. Describe instruments, studies, and data files once, then browse every instrument and variable across waves, see where the data disagree with the metadata, and run common analyses in R or Python with tables and text ready for a manuscript.

Code · Documentation

MACAW

The Multimodal Automated Coding and Analysis Workbench turns recordings of natural two-person or group interactions into an analyzable multimodal feature time series: alignment across sources, features from voice, speech, pose, face, and motion, quality control, rule-based and LLM-assisted behavioral coding, and two-way exchange with ELAN. Pre-alpha.

Code

Teaching and writing

Applied Psychological Statistics and Data Analysis in R and Python

An applied statistics manual for students in psychology and related fields who analyze their own research data in R. For each method it covers when to use it, which packages and functions to use, and common mistakes, with example code on one simulated dataset, from data cleaning to structural equation modeling with lavaan. Chapters are being added.

fMRI Data Processing Manual on HPC

A step-by-step handbook for processing fMRI data on an HPC cluster with AFNI, fMRIPrep, and XCP-D, from DICOM conversion through quality control and group analysis.

fMRI Workshop

A ten-session, hands-on workshop that takes complete beginners from raw MRI data to a reproducible fMRI analysis on an HPC cluster.

Psychology Statistics Workshop

Slides for a statistics workshop for psychology students. In progress.

Using English in Clinical Work as a Non-native Speaker

Strategies for novice counselors, therapists, and social workers who do clinical work in English as a second language, especially international students. In English and Chinese.
